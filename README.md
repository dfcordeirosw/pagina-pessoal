# Página Pessoal

Projeto desenvolvido como parte dos meus estudos em Engenharia de Software e desenvolvimento web.

## 👩‍💻 Sobre o projeto

Esta é minha primeira página pessoal desenvolvida utilizando Python e Flask, com HTML e CSS.

O projeto representa o início da minha jornada no desenvolvimento web e será atualizado conforme eu adquirir novos conhecimentos e desenvolver novos projetos.

## 🛠️ Tecnologias utilizadas

- Python
- Flask
- HTML5
- CSS3
- Git
- GitHub

## 🎯 Objetivo

O objetivo deste projeto é colocar em prática os conhecimentos adquiridos durante meus estudos e construir gradualmente meu portfólio profissional na área de desenvolvimento de software.

## 📚 Em desenvolvimento
